## Purpose

This file is the current non-destructive duplicate-control and evidence-status register for the literature records documented in `Literature_Evidence_Living.md` and `Literature_Review_Master_Index.md`. It does not overwrite the original files. It consolidates current canonical keys, duplicate/counterpart relationships, current status, planned-paper relevance, Cowork-ready inclusion, and future handling rules.

## Status Definitions

| Status | Definition | Future handling |
| ------ | ---------- | --------------- |
| Deep read completed | PDF/body evidence was read and extracted in the original Living Review. | Do not re-screen or re-read automatically. |
| Deep read completed - preprint methodological evidence | Preprint PDF/body evidence was read and extracted; use only with preprint boundary. | Do not re-read automatically unless a verified journal version is later added. |
| Limited-access evidence | Source was located or partially accessible, but complete evidence body was unavailable or incomplete. | Do not promote to substantive claims; recheck only with a newly available complete source. |
| Screened only or Ranked only | Metadata or ranking control record only. | Do not re-screen; select for future reading only if row-specific rule permits and evidence need justifies it. |
| Background only | Background/control record not suitable for automatic deep reading. | Do not deep read automatically. |
| Manual check or incomplete metadata | Metadata, DOI, title, year, or attachment issue needs human resolution. | Resolve only if an actual mismatch affects future use. |
| Full text unavailable | No usable PDF/full text was available in the documented check. | Recheck only with a newly attached complete PDF. |
| Evidence source not located | Historical candidate-pack or missing-source record without located reading evidence. | Hold for source reconciliation; do not promote. |
