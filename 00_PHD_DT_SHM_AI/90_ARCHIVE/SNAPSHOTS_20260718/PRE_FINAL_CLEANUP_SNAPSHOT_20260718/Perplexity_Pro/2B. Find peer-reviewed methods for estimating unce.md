# 2B. Find peer-reviewed methods for estimating uncertainty of classification performance

when evaluation is based on a small number of independent groups, runs,
subjects, or experimental campaigns.

Prioritize:

- grouped cross-validation;
- leave-one-group-out evaluation;
- cluster bootstrap or hierarchical bootstrap;
- confidence intervals based on independent groups rather than individual windows;
- paired comparison of classifiers or sensor configurations using group-level results.

Explain which methods remain statistically defensible with approximately six
independent runs per class.

Exclude methods that bootstrap individual time windows as if they were independent.

Now I have enough to compile a focused methodological answer.

## Direct answer

With about six independent runs per class, the statistically defensible options are grouped/leave-one-group-out cross-validation for point estimation, exact or near-exact nonparametric tests (Wilcoxon signed-rank, permutation tests) for paired comparisons, and small-sample-appropriate interval methods (Agresti–Coull/Bayesian binomial, or group-level cluster bootstrap) for confidence intervals — but all of these carry wide intervals and limited power at n≈6, so effect sizes need to be large to be detectable.[^1][^2][^3]

## Grouped cross-validation and leave-one-group-out (LOGOCV)

### Tougui et al., 2021 – "Impact of the Choice of Cross-Validation Techniques on the Results of Machine- and Deep-Learning-Based Diagnostic Applications" (PMC)

- DOI: available via PMC8369053.[^4]
- Study object: Diagnostic ML/DL applications where data naturally cluster by subject; compares k-fold, stratified k-fold, group k-fold, and leave-one-group-out CV.[^4]
- Directly supported claim: Leave-one-group-out CV, where an entire group's records are held out for testing on each fold, produces markedly different (and more realistic) performance estimates than record-level CV, because it prevents within-group leakage between train and test.[^4]
- Limitation: The comparison is empirical across several diagnostic datasets, not a formal small-sample statistical theory paper; it does not derive confidence-interval formulas for the ~6-group regime.[^4]
- Reason for inclusion: METHODOLOGICAL EVIDENCE — establishes LOGOCV as the correct point-estimate procedure for group-structured data (runs, subjects, campaigns) and quantifies the leakage risk of ignoring grouping.


### scikit-learn LeaveOneGroupOut (implementation reference)

- Reference: scikit-learn documentation on LeaveOneGroupOut, a CV scheme holding out one specified group per split.[^5]
- Reason for inclusion: NORMATIVE — standard, widely cited implementation reference confirming LOGOCV as an established, correctly-specified evaluation scheme for grouped/clustered data (not a novel statistical contribution, but the accepted operational definition you should cite for methodology).


### Defensibility at n≈6 groups per class

With only six independent groups per class, LOGOCV gives you six (or 6×classes) held-out performance values total. This is enough to compute a mean and a nonparametric CI, but not enough for stable variance estimates — Tougui et al.'s results imply the LOGOCV estimate itself is trustworthy (unbiased with respect to group leakage), while its *precision* (CI width) will be poor with so few groups. It remains defensible as a point-estimate procedure; it is the CI/hypothesis-testing step around it that needs the small-sample corrections discussed below.[^4]

## Cluster/hierarchical bootstrap for group-level confidence intervals

### Chaurasia \& Harel (or similar) – "Bootstrap ICC estimators in analysis of small clustered binary data" (Computational Statistics)

- DOI: 10.1007/s00180-019-00885-z.[^6]
- Study object: Small clustered binary outcome data with a hierarchical (multi-level) structure, directly analogous to "runs nested within class."[^6]
- What they do: Compare cluster bootstrapping (resample whole clusters/groups with replacement) versus split bootstrapping for constructing confidence intervals on intraclass correlation with small numbers of clusters.[^6]
- Directly supported claim: Cluster bootstrap (resampling groups, not individual observations) gives valid CIs for small numbers of clusters when cluster size is reasonably large and the between-cluster variance ratio is not too extreme; split bootstrap is preferred in some small-cluster-count regimes.[^6]
- Limitation: Derived for ICC estimation in clustered binary data, not directly for classifier accuracy; you would need to adapt the resampling unit (whole "run") to your accuracy metric.[^6]
- Reason for inclusion: METHODOLOGICAL EVIDENCE — the closest peer-reviewed treatment of bootstrap validity specifically as a function of the *number* of clusters, which is your key constraint (~6 per class).


### Wild cluster bootstrap (econometrics literature)

- Reference: "Wild cluster bootstrap confidence intervals," Queen's University working paper.[^7]
- What it shows: Wild cluster bootstrap was developed specifically because standard cluster-robust inference performs poorly when the number of clusters is small (they cite regimes with single digits to dozens of clusters), resampling at the cluster level using random sign-flips rather than resampling clusters directly.[^7]
- Directly supported claim: With very few clusters (in the range you describe, ~6 per class), wild cluster bootstrap gives better-calibrated CIs and test sizes than naive cluster bootstrap or asymptotic cluster-robust standard errors.[^7]
- Limitation: Developed for regression/econometric inference, not classification accuracy; adapting it to classifier performance metrics requires defining an appropriate "residual" or score to reweight per group.[^7]
- Reason for inclusion: METHODOLOGICAL EVIDENCE — directly addresses the "small number of clusters" failure mode of ordinary cluster bootstrap, which is the exact regime you're in.


### Practical takeaway for your ~6-runs-per-class case

Cluster bootstrap resamples whole groups/runs (with replacement) to build the empirical distribution of a group-level statistic (e.g., mean accuracy across held-out groups), which is the correct unit of resampling for your data — but with only six groups, the bootstrap distribution itself has limited resolution (at most $\binom{2\times6-1}{6}$ distinct resamples), so percentile intervals will be coarse and should be supplemented by wild cluster bootstrap or exact/parametric small-sample alternatives (below).[^7][^6]

## Confidence intervals from small numbers of independent groups (not windows)

### Beleites et al., 2013 – "Sample size planning for classification models" (Analytica Chimica Acta), cited via Cross Validated methodological discussion

- DOI: 10.1016/j.aca.2012.11.007.[^1]
- Study object: Classifier validation sample-size theory; explicitly works out that with very few independent test subjects (illustrated at n=4), confidence intervals on accuracy are extremely wide (e.g., observing 4/4 correct still gives a 95% CI as wide as roughly 45%–105% under Agresti–Coull, or 55%–100% under a Bayesian uniform-prior approach).[^1]
- Directly supported claim: Binomial-proportion CI methods appropriate for small n (Agresti–Coull, Bayesian with uniform prior) should be used rather than normal-approximation Wald intervals, but even so, roughly 75–100 independent test cases are typically needed for "useful precision" — meaning six per class should be reported as suggestive, not conclusive, evidence.[^1]
- Limitation: General classifier-validation statistics guidance, not vibration-specific; assumes group-level accuracy can be treated as roughly binomial (correct/incorrect classification per group), which needs each run to yield one aggregated label.[^1]
- Reason for inclusion: METHODOLOGICAL EVIDENCE — most directly quantifies what "confidence interval based on independent groups" looks like at your exact sample-size regime and gives you defensible small-sample CI formulas (Agresti–Coull, Bayesian binomial).


### Combrisson \& Jerbi, 2015 – "Exceeding chance level by chance" (Journal of Neuroscience Methods)

- DOI: 10.1016/j.jneumeth.2015.01.010.[^8]
- Study object: Small-sample brain-signal classification, directly parallel in structure (few independent decoding runs/subjects, binary/multiclass accuracy).[^8]
- What they do: Show empirically that theoretical chance levels are unreliable with small sample sizes and propose binomial cumulative-distribution and permutation-test-based significance thresholds that correctly account for sample size, cross-validation scheme, and number of classes.[^8]
- Directly supported claim: Permutation testing (shuffling labels across the small number of independent groups, not within groups) gives a valid empirical null distribution for accuracy even when n is small, correctly widening the required accuracy threshold for significance as n shrinks.[^8]
- Limitation: The permutation approach requires enough enumerable label permutations to build a meaningful null; with exactly six groups per class, the total number of distinct permutations is limited, so p-value resolution is coarse (minimum achievable p-value ≈ 1/number of permutations).[^8]
- Reason for inclusion: DIRECT EVIDENCE — directly transferable framework for significance testing of classification accuracy at small group counts, matching your evaluation unit (groups, not windows).


### Ojala \& Garriga, 2010 – "Permutation Tests for Studying Classifier Performance" (JMLR)

- Reference: JMLR volume 11.[^3]
- Study object: General framework for permutation-based significance testing of classifier accuracy, distinguishing label permutation from the full training/evaluation pipeline.[^3]
- Directly supported claim: Permutation tests remain valid with small sample sizes because they do not rely on asymptotic normality; the p-value is exact relative to the number of permutations performed, which is well-defined even for n≈6 per class.[^3]
- Limitation: With very small n, the exact permutation p-value has a coarse minimum resolution and multiple-comparison correction becomes important if many sensor/model configurations are tested.[^3]
- Reason for inclusion: METHODOLOGICAL EVIDENCE — foundational, widely cited reference for defensible significance testing at small group counts.


## Paired comparison of classifiers or configurations at the group level

### Wilcoxon signed-rank test (paired, group-level)

- Standard reference for the paired nonparametric test; used across multiple validated applications for comparing algorithms group-by-group.[^9][^10][^11]
- Directly supported claim: When you have six paired group-level scores (e.g., accuracy of configuration A vs configuration B on the same six runs), the Wilcoxon signed-rank test is the standard nonparametric choice; it doesn't assume normality but at n=6 its exact null distribution has few attainable p-values, so even a perfect ranking may only reach p≈0.03–0.06 rather than a very small p-value.[^11]
- Limitation: Power is low at n=6; a real, non-trivial effect can fail to reach conventional significance thresholds purely due to the tiny sample. Report effect sizes (e.g., median difference, Cohen's r) alongside the test.[^11]
- Reason for inclusion: DIRECT EVIDENCE — this is the appropriate paired test for group-level (not window-level) comparisons of two sensor configurations or classifiers under your protocol.


### Demšar, 2006 – "Statistical Comparisons of Classifiers over Multiple Data Sets" (JMLR)

- Reference: JMLR volume 7.[^12]
- Study object: Statistical methodology for comparing classifiers across multiple independent datasets/folds (directly analogous to comparing configurations across multiple independent runs).[^12]
- Directly supported claim: For pairwise comparison across a modest number of independent datasets/runs, the Wilcoxon signed-rank test is recommended over the paired t-test because it doesn't assume normally distributed differences and is more robust to outliers; for comparisons among more than two configurations, Friedman test with post-hoc Nemenyi is recommended, but both require reasonably many independent units (typically ≥10) to have adequate power — at n=6 results should be treated as exploratory.[^12]
- Limitation: Demšar's guidance is calibrated more for ≥10 datasets; explicitly flags that very small numbers of comparison units reduce these tests to low-power, coarse-resolution tools.[^12]
- Reason for inclusion: DIRECT EVIDENCE — the canonical peer-reviewed reference for exactly this "compare classifiers/configurations across independent units" problem, including explicit caveats about small-n regimes.


## Summary of defensibility at ~6 independent runs per class

| Method | Peer-reviewed source | Defensible at n≈6/class? | Caveat |
| :-- | :-- | :-- | :-- |
| Leave-one-group-out CV (point estimate) | Tougui et al. 2021 [^4] | Yes, for unbiased point estimate | CI around the estimate will be wide; not a substitute for a proper interval method |
| Cluster bootstrap (resample groups) | Chaurasia/Harel-style paper [^6] | Marginal | Coarse resolution with only 6 clusters; consider wild cluster bootstrap instead |
| Wild cluster bootstrap | Cameron/Gelbach/Miller-style paper [^7] | Yes, more robust than plain cluster bootstrap | Originally regression-focused; needs adaptation to accuracy metrics |
| Agresti–Coull / Bayesian binomial CI on group-level accuracy | Beleites et al. 2013 [^1] | Yes, recommended | Intervals will be very wide (e.g., ±25–50 points) at n=6 |
| Permutation test (shuffle group labels) | Combrisson \& Jerbi 2015 [^8]; Ojala \& Garriga 2010 [^3] | Yes | p-value resolution limited by number of possible permutations |
| Wilcoxon signed-rank (paired group comparison) | Demšar 2006 [^12] | Yes, but low power | Effect must be large to reach significance; report effect size alongside p-value |
| Friedman + Nemenyi (multi-way comparison) | Demšar 2006 [^12] | Marginal | Recommended n is ≥10 datasets; treat n=6 results as exploratory |

For your PhD chain, the most defensible combination given ~6 independent runs per class is: LOGOCV for the point estimate, Agresti–Coull or Bayesian binomial intervals (or wild cluster bootstrap) for the confidence interval on group-level accuracy, and Wilcoxon signed-rank or an exact permutation test for paired comparisons between sensor configurations or classifiers — all explicitly avoiding any bootstrap or CI construction over individual time windows, since window-level resampling would violate the independence assumption these methods require.[^12][^4][^6][^7][^8][^1]
