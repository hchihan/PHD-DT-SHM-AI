# MẪU YÊU CẦU TẠO PROMPT

Sao chép mẫu ngắn này vào chat:

```text
Mô hình đích:
Nhóm nhiệm vụ:
Mục tiêu:
Nguồn đầu vào:
Đầu ra:
Ràng buộc:
Độ dài prompt:
```

## Mẫu siêu ngắn

```text
Tạo prompt cho [MÔ HÌNH].
Mục tiêu: [...]
Nguồn: [...]
Đầu ra: [...]
Giới hạn: [...]
```

## Mẫu yêu cầu rút gọn

```text
Rút prompt dưới đây còn tối đa [số từ].
Giữ nguyên mục tiêu, nguồn, ràng buộc và đầu ra.
Chỉ trả về prompt đã rút gọn.

[PASTE PROMPT]
```
