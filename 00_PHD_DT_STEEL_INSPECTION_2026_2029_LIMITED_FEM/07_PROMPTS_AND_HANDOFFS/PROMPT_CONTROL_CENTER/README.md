# PROMPT CONTROL CENTER

Project tổng thể dùng để quản lý và tạo prompt cho nhiều mô hình AI, nhiều lĩnh vực và nhiều mục tiêu.

## Cách tạo Project trong ChatGPT

1. Chọn `New project`.
2. Đặt tên: `PROMPT CONTROL CENTER`.
3. Chọn `Project-only memory` nếu muốn không gian này tách khỏi các chat khác.
4. Mở `Project settings`.
5. Dán nội dung file `00_PROJECT_INSTRUCTIONS.md` vào Project instructions.
6. Tải các file còn lại vào Project làm tài liệu điều khiển.
7. Tạo các chat chuyên mục theo danh sách bên dưới.

## Chat đề xuất

- `[CONTROL] Prompt Router`
- `[RESEARCH] Academic & Literature`
- `[DATA-CODE] Analysis & Automation`
- `[WRITING] Reports, Emails & Content`
- `[TEACHING] Lessons & Assessment`
- `[BUSINESS] Marketing & Management`
- `[ENGINEERING] Construction Tasks`
- `[DOCUMENTS] Word, Excel, PPT & PDF`
- `[VISUAL] Images & Design`
- `[PERSONAL] Planning & Communication`
- `[PHD] Thesis Prompt Operations`
- `[REVIEW] Prompt Compressor`

## Nguyên tắc

Project là nơi quản lý bối cảnh, thư viện và các chat. Skill là quy trình tái sử dụng. Có thể dùng Project này cùng các Skill đã tạo trước đó.
