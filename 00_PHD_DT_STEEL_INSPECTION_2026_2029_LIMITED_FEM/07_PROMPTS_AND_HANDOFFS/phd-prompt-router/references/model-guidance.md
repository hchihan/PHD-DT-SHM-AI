# Target-model guidance

## NotebookLM
Use only loaded sources. Require page, section, figure, table, or listing references. Separate source statements from inference. Best for deep reading, evidence mapping, and literature synthesis.

## Claude Code
State the allowed folder/files, required checks, exact output file, and whether files may be modified. Preserve raw data by default. Best for data audits, run registries, reproducible analysis, and code validation.

## Perplexity
Specify source type, date range, inclusion/exclusion rules, and verification requirements. Prefer primary papers, official standards, and publisher pages. Best for literature discovery and current-source verification.

## Claude, Gemini, or ChatGPT
Specify the source of truth, target artifact, evaluation criteria, and scope boundaries. Best for synthesis, critical review, matrices, outlines, and revision.

## Default prompt length
Use 120–300 words. Extend to 500 words only for complex data workflows or multi-source deep reading.
